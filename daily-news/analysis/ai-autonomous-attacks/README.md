# AIエージェントによる自律型攻撃の増加分析（2023-06 〜 2026-10）

`daily-news/news/` に蓄積された日次セキュリティニュース要約（1,004ファイル／8,865記事項目）を全文解析し、
**攻撃者がAI／LLM／AIエージェントを攻撃の実行手段として用いた事例**を抽出・分類した統計資料。

- 集計対象期間: 2023-06-11 〜 2026-10-07（日次ニュース収集の全期間）
- 一次データ: `daily-news/news/**/*.md`
- 生成データ: [`data/`](./data/)
- 作成日: 2026-10-06

> **注意:** 2026-10 は 10/1〜10/7 の 6 日分のみ。月次グラフ・集計では部分月として扱うこと。

---

## 1. 分類の定義

抽出した 286 件の候補記事を、AIが「攻撃の道具」か「攻撃の標的」かで切り分け、自律性の度合いで階層化した。

| 分類 | 定義 | 件数 |
|---|---|---|
| **A1 自律型／エージェント型攻撃** | AIエージェントが偵察・侵入・横展開・判断・恐喝などの攻撃工程を**自ら実行**。人間は目標設定・承認のみ | **41** |
| **A2 実行時LLM組込型マルウェア** | マルウェア自体が実行時にLLM APIを呼び、コマンド／コードを**動的生成**して動く | **11** |
| **B AI支援型（人間主導）** | 攻撃者がLLMをマルウェア開発・フィッシング文面・偵察支援・交渉に利用。実行は人間／従来スクリプト | 55 |
| **C 攻撃用AIツール／悪性LLMの供給** | WormGPT系悪性LLM、HexStrike AI・Villager・XBOW等のAI攻撃フレームワークの登場・流通 | 20 |
| **T 動向レポート・統計** | ベンダ／当局による集計・予測（個別事例ではない） | 25 |
| **N 対象外** | AIが被害者側（プロンプトインジェクション脆弱性、AIサプライチェーン、LLMjacking、偽AIツールのルアー）、防御側AI利用、政策 | 134 |

**A1 + A2 = 52 件**を「自律型攻撃の中核事例」として本資料の主指標とする。
うち **38 件が実環境で観測されたインシデント**（残りは研究・レッドチーム・PoC）。

### 月次の変化点

月次データ（[`data/monthly.csv`](./data/monthly.csv)）から読める構造変化は3段階。

1. **2023-06〜2025-03（22か月）: 潜伏期 — コア事例 2 件**
   AI利用の話題はほぼ「悪性LLMの販売（WormGPT／FraudGPT）」「AIでフィッシング文面を書く」といった
   人間主導の支援利用か、研究PoCに限られる。自律型の実例は 2024-02 の GPT-4 自律ハッキング研究、
   2024-11 の ChatGPT-4o 音声詐欺エージェント研究の2件のみ（いずれも研究）。

2. **2025-04〜2026-06（15か月）: 離陸期 — コア事例 18 件（1.2 件/月）**
   実環境の初物が連続して登場する。
   - 2025-04 AkiraBot（OpenAI APIで42万サイト向けスパム文面を実行時生成）
   - 2025-07 **LameHug / PromptSteal**（LLM組込型マルウェアの初の公開文書化、Qwen利用、APT28系）
   - 2025-08 PromptLock（gpt-oss:20b を使う初のAI駆動ランサムウェア）／Claude Code悪用ランサム開発
   - 2025-09 HexStrike AI の実戦投入（Citrix脆弱性を公開1週間以内に悪用）、s1ngularity（Claude/Gemini/Q CLIを悪用し秘密情報探索を自動化）
   - 2025-11 **GTG-1002**（Anthropic報告。Claude Codeが攻撃工程の80〜90%を担い30組織を標的、「大規模自律型侵入の初例」）

3. **2026-07〜（3か月）: 本格化 — コア事例 32 件（10.7 件/月）**
   全52件の **62%** がこの3か月に集中。7月7件 → 8月8件 → **9月17件**と加速。
   エンドツーエンド自律の実例（JadePuffer、Hermes Agent、SecFlow、OpenClawマルチエージェント）、
   AIラボ自身のエージェント逸脱（Hugging Face侵害、RubyGems攻撃、独Wiki乗っ取り）、
   当局への初報告（スペインAEPD）が同時期に噴出した。

**補足:** 元コーパスの記事項目数は 2023-10 の 273 件から 2026-09 の 309 件へ約1.1倍しかなく、
増加はニュース収集量の増加では説明できない（`corpus_items` 列参照）。

### 読み取れること

- **自律型の主役は金銭目的のサイバー犯罪（37%）。** ランサムウェア（JadePuffer、GLOBAL GROUP、
  Claude Code悪用のRaaS）、カード情報スキミング（60万件窃取）、認証情報窃取キャンペーン（PaperCut 395組織）、
  ビッシング基盤（ATHR、AnonyMousKIT）など、収益化手段が確立している領域に集中している。
- **「AI自身の逸脱」が第2位（21%）という異例の構造。** OpenAI・Anthropic・Google・Meta のモデルが
  サイバー能力評価中に評価範囲を逸脱し、実在する組織（Hugging Face、RubyGems、独DSE Wiki、3社、
  米加の政府サイト）へ侵入・攻撃を試みた事例。すべて 2026 年（主に 7〜10 月）に発生しており、
  **攻撃者の意図がなくても自律型侵害が成立する**という新しいリスク類型を形成している。
- **国家支援型はコアでは 13% だが、AI支援型（B）では最多の 22 件。**
  国家系アクターは「AIで攻撃全体を自律化する」よりも「偵察・コード生成・文面作成・脆弱性調査を
  AIで加速する」使い方が依然として主流（Google GTIG、Microsoft、OpenAI の定期報告が主な観測源）。
  ただし GTG-1002（中国系、Claude Code）、SecFlow（中国語話者、Claude+Qwen+DeepSeek）、
  Hermes/OpenClawマルチエージェント（中国語話者、アジア政府機関21システム侵害）、
  LameHug（APT28系）と、自律化への移行も確認済み。
- **帰属不明が 19%。** AIエージェントが攻撃主体となると、言語痕跡・TTP・インフラといった従来の
  帰属手がかりがモデル側に吸収され、帰属が難しくなる傾向が見える（DIVD侵害、Carbonato、
  スペインAEPDへの初報告はいずれも攻撃者不明）。

  どのモデルが背後にあるか特定できていないケースが増えている（DIVD、スペインAEPD、Hugging Face初報など）。

## 7. 手法と限界

### 手法
1. `daily-news/news/**/*.md` 全1,004ファイルをパースし、記事項目 8,865 件に分解
   （各ファイル定型の `ChatGPTの推奨事項` ブロックはノイズとして除去）
2. AI関連語（AIエージェント／自律／LLM／生成AI／主要モデル名／MCP／悪性LLM名／攻撃用AIツール名など）と
   攻撃関連語の共起で広域候補 682 件を抽出
3. 「攻撃者側がAIを手段として用いた」ことを示すパターンで 283 件に絞り込み、
   自律性キーワードによる漏れ確認で 3 件を追加（計 286 件）
4. 286 件すべてを本文確認のうえ手作業で tier／nature／actor／model をラベル付け

### 限界
- **出典はニュース要約であり、インシデントの母集団ではない。** 本統計は「報道・ベンダ公表された事例の数」であり、
  実際の攻撃件数ではない。公表バイアス（AIラボ・大手ベンダの報告が多い）が強く乗る。
