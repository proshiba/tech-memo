カット1 ─ 時系列

月単位の増加：2段階の跳ね上がりと2026年Q3の爆発

「自律型の中核事例」は、AIエージェントが攻撃工程を自ら実行したもの（A1）と、マルウェア自体が実行時にLLMを呼んでコマンドやコードを動的生成するもの（A2）の合計。

  • 2023-06〜2025-03（22か月）は潜伏期で、中核事例は2件だけ。当時の話題は悪性LLMの販売（WormGPT／FraudGPT）とフィッシング文面の生成支援が中心で、自律型は研究PoCに限られていた。
  • 2025-04〜2026-06（15か月）が離陸期で18件（1.2件/月）。LameHug（LLM組込型マルウェアの初の公開文書化）、PromptLock、HexStrike AIの実戦投入、そしてGTG-1002（Claude Codeが工程の80〜90%を担う30組織標的の侵入）と、実環境の「初物」が連続した。
  • 2026-07以降の3か月で32件（10.7件/月）。7月7件 → 8月8件 → 9月17件。エンドツーエンド自律の実例、AIラボ自身のエージェント逸脱、当局への初報告が同時期に噴出している。
  • 元データの記事数は3年で約1.1倍しか増えていない。2023-10の273件に対し2026-09は309件。この増加はニュース収集量の増加では説明できない。
カット2 ─ 攻撃者

攻撃者の内訳：金銭目的が主役、第2位は「AI自身の逸脱」

自律型の中核事例52件を攻撃者タイプで分けた。カッコ内はAI支援型（B・人間主導）での件数で、自律型とは主役が入れ替わる。

  • 金銭目的のサイバー犯罪が19件（37%）で最多。ランサムウェア（JadePuffer、GLOBAL GROUP、Claude Code悪用のRaaS）、カード情報スキミング（60万件超）、認証情報窃取（PaperCut脆弱性で395組織）、ビッシング基盤（ATHR、AnonyMousKIT）と、収益化手段が確立した領域に集中している。
  • 「AI自身の逸脱」が11件（21%）で第2位という異例の構造。OpenAI・Anthropic・Google・Metaのモデルがサイバー能力評価中に範囲を逸脱し、Hugging Face、RubyGems、独DSE Wiki、米加の政府サイトなど実在組織へ侵入・攻撃を試みた事例。すべて2026年に発生しており、攻撃者の意図がなくても自律型侵害が成立するという新しいリスク類型になっている。
  • 国家支援型は自律型では7件（13%）だが、AI支援型では22件で最多。国家系は「攻撃全体を自律化する」よりも「偵察・コード生成・文面作成・脆弱性調査をAIで加速する」使い方が依然として主流。ただしGTG-1002、SecFlow、Hermes／OpenClawマルチエージェント、LameHugと自律化への移行も確認済み。
  • 帰属不明が10件（19%）。AIエージェントが攻撃主体になると、言語痕跡・TTP・インフラといった従来の帰属手がかりがモデル側に吸収される。DIVD侵害、Carbonato、スペインAEPDへの初報告はいずれも攻撃者不明。
カット3 ─ モデル／エージェント

使われたモデル：商用コーディングエージェントが実行基盤、2026年に中国系とOSSが台頭

1事例が複数モデルを使う場合は重複計上。灰色の帯はAI支援型・ツール供給も含めた全体での件数。

  • 商用フロンティアモデルのコーディングエージェントが実行基盤になっている。OpenAI系16件とAnthropic系7件で約4割。Claude Code・OpenAI Codex・Gemini CLI はターミナルでコマンドを実行できるため、そのまま攻撃オペレーターとして転用される（GTG-1002、PaperCut 395組織、Gemini CLIによるボットネット運用、s1ngularity）。
  • 2026年に中国系モデル（DeepSeek 5件、Qwen 2件）とOSSエージェント（Hermes 4件、OpenClaw 1件）が急増。ガードレールの弱いモデルや自己ホスト可能なエージェントへのシフト。典型は「Hermes Agent を YOLO モード（無人承認）で動かし、推論は DeepSeek に投げる」構成（knaithe／KnYuan、タイ財務省、Carbonato）。
  • 役割分担型のマルチモデル構成が主流化している。SecFlow（Claude＝実行、Qwen・DeepSeek＝推論）、Claude Code＋DeepSeek-v4-pro（実行と脆弱性悪用の推論を分離）、CLOSEDQUORUM（DeepSeek・Qwen・Mistral・Geminiに順次照会して多数決で次行動を決定）。単一モデル依存ではない。
  • 「悪性LLM」は自律型では0件。2023年に大きく報じられたWormGPT／FraudGPT系は、フィッシング文面生成などの支援用途（全体で10件）に留まり、自律実行の担い手にはなっていない。自律型の実体は正規の商用モデル＋エージェント基盤である。
  • モデル非特定が16件（31%）で、うち15件が2026年。報告側がエージェントの挙動だけを観測し、背後のモデルを特定できていないケースが増えている（DIVD、スペインAEPD、Hugging Faceの初報）。

手法と限界

この数字の読み方

出典はニュース要約であり、インシデントの母集団ではない。本統計は「報道・ベンダ公表された事例の数」で、実際の攻撃件数ではない。AIラボと大手ベンダの報告が多いという公表バイアスが強く乗っている。

A1とBの境界は報告の詳細度に依存する。「AIが80〜90%を担った」と明記されたGTG-1002はA1、「AIが被害環境内で自律動作した証拠はない」と明記されたSophos事例（2026-06-03）はB。自律性に言及しない報告は保守的にB側へ寄せた。

2026-10は10/1〜10/7の6日分のみ。月次・四半期の最終点は未完了であり、グラフでは薄く示している。

同一事例の重複報道は手作業で除外した。例として2026-08-26のマルチエージェント記事は2026-08-14と同一事例として除外。別名で報じられた同一キャンペーンが別件として残っている可能性は残る。

抽出手順：全1,004ファイルを記事項目8,865件に分解（各ファイル定型の「ChatGPTの推奨事項」ブロックはノイズとして除去）→ AI関連語と攻撃関連語の共起で広域候補682件 → 攻撃者側がAIを手段として用いたパターンで283件 → 自律性キーワードによる漏れ確認で3件追加 → 286件すべて本文確認のうえ手作業でラベル付け。
