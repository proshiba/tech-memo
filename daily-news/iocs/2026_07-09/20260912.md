## category 判定についての注意点

- Anthropic レポートの付録は、アクター単位で「Domains」「IP Addresses」などと列挙するのみで、指標ごとの役割 (C2 / フィッシング / 配布) を明示していない。推測を避け、役割が読み取れないものは `category = unknown` とした。
- 一方で「Attacker Egress IPs」「Actor Egress IP Infrastructure」と明示されているものは `srcip`、「Exfiltration Locations」「Actor-Owned Domains and Services」と明示されているものは `c2` とした。
- Anthropic レポートの egress IP には観測期間が併記されているため、`date` には観測期間の開始日を採用した。期間が年月までしか示されていないものは日付を創作せず `news_date` (2026-09-12) を採用した。
- Anthropic レポート自体の公開日は「September 2026」までしか特定できなかったため、観測日が明記されていない指標の `date` は `news_date` (2026-09-12) とした。
- Microsoft の15ドメインは Storm-3121 / Storm-3032 双方が関与する同一エコシステムのIOC表として公開されており、ドメインごとのアクター対応は一次ソースに記載がない。そのため `actor` は `Storm-3121 / Storm-3032` と併記した。
- Wiz の Rust 製バックドアには一次ソースで名称が付与されていないため `malware = unknown` とし、`malware_type = backdoor` のみ記録した。
- KATARU は Mirai 系のIoTマルウェアだが、一次ソースが明示的な分類 (worm / backdoor 等) を示していないため `malware_type = unknown` とした。
- KATARU の `160.191.242.92` は一次ソースでブルートフォース送信元かつC2と説明されている。重複排除キーの制約上1行にまとめ、`category = c2` とし description に送信元である点を記載した。
