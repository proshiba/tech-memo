### 1. Sogou Input Method の1クリックRCEとGRAYRABBITバックドア

- ニュース記事 (BleepingComputer) 本文にはIOCの記載がなく、ニュースファイル内に明記されていた一次ソース (Gen Digital の調査レポート) を確認した。
- 一次ソースのIOCセクションから、SHA256 3件、domain 2件、IP 1件を収集した。
- 各ハッシュの役割 (トロイ化DLLローダー、暗号化PEローダーシェルコード、GRAYRABBITバックドア本体) がレポートに明記されていたため、category を `related-file` / `malware` に振り分けた。
- C2ドメインは TCP/443 上の RC4 暗号化通信、もう1件のドメインは WebView に読み込ませる Exploit ホスティング先、IP は Alibaba Cloud 香港リージョン上のステージングサーバとして明記されている。
- actor は `UNC3569`、actor_attribute は一次ソースの PRC-nexus 記述に基づき `china`、malware は `GRAYRABBIT` / `backdoor` とした。
- IOC個別の観測日はレポートに記載がなかったため、date は一次ソースの公開日 2026-09-10 を使用した。
- SHA256のうち1件は一次ソース上で先頭が大文字表記だったため、照合用に小文字へ正規化した。defang表記 (`[.]`) も正規化済み。

### 2. オランダNCSC Check Point VPN アドバイザリ

- 公開PoCや実際の悪用も未報告であり、収集対象のIOCなし → `no_ioc_found`。

### 3. RubyGems に対する自律エージェント攻撃 (rubyhack.ai)

- 元記事自体が調査レポートであり、IOCも記事内にあるため、記事URLを一次ソースとして扱った。別途のIOC公開ページ・付録は存在しなかった。
- レポートに登場する識別子を確認したが、本Routineの収集対象 (ip / domain / url / file hash) に該当し、かつ攻撃者インフラとして明示されているものは存在しなかったため `no_ioc_found` とした。
- 収集対象外・ノイズとして除外した主なもの:
  - `rubygems.org` / `rubydoc.info` / `r.jina.ai`: 悪用された正規サービスのトップレベルドメインであり、IOCとして明示されていない。
  - 英国地方自治体の各Webサイト (Lambeth / Wandsworth / Southwark など) および `sec.gov`: 攻撃対象・収集対象であって攻撃者インフラではない。
  - `example.com`: レポート内でもドキュメント用予約ドメイン/プレースホルダとして扱われており、実インフラではない。
  - 悪性RubyGemsパッケージ名 (2,000件超): `package_name` は収集対象外。レポートはパッケージ名のみを列挙しており、個別のRubyGems URLをIOCとして明示していないため、URLの推測生成は行わなかった。
  - メールアドレス、APIキー、`hack.rb` などのファイル名、CVE番号: いずれも収集対象外。

## 除外したノイズの概要

- 正規サービスのトップレベルドメイン (rubygems.org, rubydoc.info, r.jina.ai など)。
- 被害組織・調査対象の正規Webサイト (英国地方自治体サイト、sec.gov)。
- 予約済みドキュメントドメイン (example.com)。
- 収集対象外の識別子種別 (email, package_name, file_name, APIキー, CVE)。
