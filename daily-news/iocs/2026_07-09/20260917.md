### 2. マルウェアがブラウザのチェックを回避し、Chrome・Edge拡張機能を強制インストール

- 記事URL（secondary）: https://www.bleepingcomputer.com/news/security/malware-bypasses-browser-checks-to-force-install-chrome-edge-extensions/
- 一次ソース（primary）: https://www.elastic.co/security-labs/threat-command/malicious-browser-extension-kremlin-banking-malware （公開日 2026-09-14）
- IOC公開ページ: https://github.com/elastic/labs-releases/tree/main/indicators/kremlin
- 結果: IOC 173件を収集（SHA256 127件、URL 30件、domain 10件、IP 6件 ※重複排除後）。
- 検証内容:
  - 一次ソース本文をHTMLから抽出し、記事中に記載されたハッシュ・IP・ドメインを機械的に抽出して照合した。
  - 一次ソースが「indicators are also available for download here」として案内するGitHub上のIOC公開ページ（README）を取得し、Network indicators / File indicators のテーブルを機械的にパースして採用した。
  - reference は、より網羅的なIOC公開ページ（GitHub）を採用した。
  - date は IOC公開ページの `First seen (UTC)` 列を採用した。
- 分類方針:
  - Network indicators（URL/domain/IP）はすべて `c2`。
  - File indicators はIOC公開ページの Type 列に基づき、Loader/Installer/RunPE/PULSAR/REMCOS/Extension/Persistence script を `malware`、JPEG carrier/Host list/CAB を `related-file`、署名済み正規バイナリ（サイドローディング悪用）を `abusefile` とした。
  - actor は一次ソースが明記する `REF9334`、actor_attribute はブラジルの銀行を標的とした金銭目的の活動と明記されているため `cybercrime` とした。
- 除外したもの:
  - Windows artifact indicators（ファイルパス、レジストリキー、Mutex、コマンドライン）は収集対象外のため除外。
  - Ethereum スマートコントラクトアドレス、ウォレットアドレス、拡張機能ID、customer ID、メールアドレスは収集対象外のため除外。
  - コマンドライン例に含まれる `8.8.8.8` はノイズ（正規DNS）として除外。
  - CDN由来の解決先IP（Cloudflare等）は一次ソースのIOCテーブルに含まれないため不採用。

  - IPv4 / Domain は `c2`、ハッシュは `malware`、malware は `Noodle RAT`、malware_type は `RAT`。
  - 記事は Iron Tiger、Calypso APT、Rocke、Cloud Snooper 等の複数グループによる利用に言及しているが、個々のIOCと特定アクターの対応付けは明記されていないため、actor / actor_attribute はいずれも `unknown` とした。
