## 注意点

- **ニュースファイルで「IOC情報なし」の記事からの収集**: FaceStealer (Arctic Wolf)、Cursor、Enea の3記事はニュースファイル上は「IOC情報なし」でしたが、一次ソースを確認した結果IOCが公開されていたため収集しました。特に Arctic Wolf はブログ本文ではなくリンク先ホワイトペーパーPDFの APPENDIX 1 にIOCが集約されており、本CSVの159件 (約60%) を占めます。
- **Cursor のURL誤り**: ニュースファイル記載の一次ソース `https://cursor.com/blog/security-notice-claude-code-extension` は HTTP 404 でした。実在する 10-29 通知は `https://cursor.com/blog/claude-code-extension-security-notice` で、こちらをIOC公開ページとして採用しています。`date` は通知記載の攻撃活動期間 (2026年10月29日 2:27-13:35 PT) に基づき 2026-10-29 としました。
- **Arctic Wolf の高確度ドメイン件数**: 報告書は「HIGH Confidence (98)」と記載していますが、カテゴリ別の列挙を機械的に抽出すると99件になります。本CSVは実際に列挙されている99件をすべて採用しました。
- **Arctic Wolf の category 判断**: ルアー用ドメイン・サブドメインとHostwinds の3IPは偽会議ページ・偽アプリ配布ページを提供するため `phishing-site` としました。`updatesdk.*` サブドメインは一次ソースが「ClickFix "SDK update" payload hosts」と明記しているため `payload-hosting`、`camera.call-in.co` 等の「Backend / capture infrastructure」は攻撃者バックエンドとして `c2` としています。`docview.ink` は update.ps1 の取得元ですが MEDIUM Confidence ドメイン一覧のルアークラスタの一部であり、方針どおりフィッシング兼配布は `phishing-site` に寄せ、個別のペイロード取得URLのみ `payload-hosting` としました。
- **Arctic Wolf の per-target サブドメイン**: `hashkey.team-meet.xyz` 等は報告書が「Targeting does not establish compromise」と明記しており、標的組織の侵害を意味しません。description に注記しています。
- **Arctic Wolf のハッシュ**: APPENDIX 1 のハッシュはPDF上で2行に折り返されているため、連結後に SHA256 64桁 / MD5 32桁になることを検証して採用しました。YARA ルールの `meta` に記載されたSHA256 3件も検体ハッシュとして採用し、description に出典を明記しています。ディープフェイク動画2件はアップロード日 (2026-06-26 / 2026-09-01) を観測日として採用しました。
- **Fortinet の domain 表記**: IOC節は `site.vietnam852[.]com:88` のようにポートを付けて列挙していますが、domain はホスト名のみを記録する規則に従いポートを除去しました。ポート情報は description では扱わず、Gh0st RAT の C2 2件のみ「port 8000」として記載しています。
- **Fortinet の c2 / payload-hosting 切り分け**: `site.vietnam852.com` は配布に加えて `ip.php` (探索範囲の取得) と `tj/xmr.php` (採掘状況の報告)、`ftp.vietnam852.com` は配布に加えて `post.php` (侵害端末情報の送信) に使われているため、方針どおり `c2` を優先しました。配布専用と判断できる `site.jiancai008.com` のみ `payload-hosting` としています。`tj/xmr.php?data=` の2件は一次ソースがクエリ接頭部の形で列挙しているため、推測で値を補わず原文のまま採用しました。
- **Fortinet の hash category**: `dllhost.exe` (Naabu 組み込みのスキャナ) と `dwm.exe` (総当たりツール) は攻撃ツールとして `tool`、正規の `sqlcmd.exe` は `abusefile` としました。マルウェアファミリ名が明記されていない検体の `malware` 列は `unknown` です。
- **Unit 42 の帰属**: Unit 42 は Falcon を特定の攻撃主体に帰属させていないため `actor` / `actor_attribute` は全件 `unknown` としました (Additional Resources にある Talos の UAT-11587 への帰属は採用していません)。拡張のアイコン画像・HTML・manifest は `related-file`、JavaScript は `malware` に分類しています。Chrome 版と Firefox 版で同一ハッシュのファイルは重複排除し、両版に存在する旨を description に記載しました。
- **Unit 42 の配布URL**: `https://microsoft-flash.com/download/Adobe_installer.exe` はIOC節ではなく本文中に「The payload was served from ...」として明記されているものです。一次ソースで配布先と明示されているため採用しました。
