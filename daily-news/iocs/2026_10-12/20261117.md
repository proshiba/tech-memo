## 判断根拠と除外したノイズの概要

### categoryの判断

- **Cisco Talos の 2546 IP → `c2`**: 一次ソースが "ARTEX-associated C2 IP addresses" と明記しているため。ペイロード配布専用である旨の記載はないため `payload-hosting` は付けていない。
- **Amazon の 11 IP → `srcip`**: MadPotセンサーへ到達したARTEXエージェント要求の送信元IPであり、攻撃通信の送信元に該当するため。
- **Barracuda の 4 IP → `srcip`**: 侵害調査のためのIndicators of Compromiseとして提示されたIPで、不正アクセス通信側の指標であるため。

### actor / actor_attribute / malware の判断

- Talos・Barracudaの指標は一次ソースで特定アクターへ帰属されていないため `actor=unknown` / `actor_attribute=unknown`。
- Amazonの指標のみ、一次ソースが「中程度の確度で複数の中国関連集団」と明記しているため `actor_attribute=china`。集団名の記載はないため `actor=unknown`。
- いずれの一次ソースもマルウェアファミリ名を指標に紐付けていないため `malware`/`malware_type` は `unknown`。ARTEXはAI侵入テスト基盤でありマルウェア名ではないため、malware欄には記載していない。

### 除外したノイズの概要

- Talos IOCファイル1行目の見出し行 `ARTEX IPs:` を非IOCとして除外。
- 正規化・検証時に private / loopback / link-local / multicast / reserved / documentation レンジ、および `1.1.1.1` `8.8.8.8` `8.8.4.4` `127.0.0.1` `0.0.0.0` を自動除外する処理を適用したが、該当する値は0件だった。
- `104.28.x.x` 等のCDN事業者レンジに属するIPは、一次ソースがIOCとして明示しているため除外していない。
- 収集対象外として扱ったもの: CVE番号 (CVE-2026-99288 ほか)、ファイル名・パス (`exploit_agent`、`v21925.php`、`.claude/settings.json`、`i19ghci.yml`)、User-Agent文字列 (Barracudaアドバイザリ記載の5件)、Linuxカーネルのcommit hash 2件、マルウェア名・ツール名のみの記載 (SOMBERMEME、ARTEX、CAIRN、CyberStrikeAI、HexStrike AI、PentAGI など)、攻撃グループ名のみの記載 (UNC6836、VAPOR PANDA、Storm-0940、Storm-3358、CALANQUE ION、LEAKY CASTLE、MIDNIGHT NEPTUNE)。
