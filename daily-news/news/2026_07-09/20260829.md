#### McKesson、ShinyHuntersが患者データ窃取を主張する中で侵害を公表
https://www.bleepingcomputer.com/news/security/mckesson-discloses-breach-after-shinyhunters-claims-patient-data-theft/

- 要約
    - 医薬品流通大手McKessonは、サードパーティアプリケーションへの不正アクセスとデータ流出を伴うサイバーインシデントを8月25日に発見したと公表した。

#### GiveWP WordPress寄付プラグインの脆弱性、攻撃者によるサーバーコマンド実行を可能に
https://www.bleepingcomputer.com/news/security/givewp-wordpress-donation-plugin-flaw-lets-hackers-execute-server-commands/

- 要約
    - WordPress向け寄付プラグインGiveWPに、未認証攻撃者がホスティングサーバー上で任意コマンドを実行できる最大深刻度のCVE-2026-82222が確認された。
    - 攻撃は安全でないPHPデシリアライズ処理、攻撃者制御のシリアライズオブジェクトを保存する寄付処理、同梱ライブラリのガジェットチェーンを組み合わせて成立する。
    - GiveWPにはWordPressの登録設定を無視する未認証ユーザー登録処理があり、通常は必要なアカウントを攻撃者自身で作成してRCEチェーンを進められる。
    - 4.16.6～4.16.7.1でも、旧式の寄付フォームが残るアップグレード環境や旧フォームを復元・インポートした環境などでは引き続き悪用可能である。
    - GiveWPは8月27日公開の4.16.7.2でシリアライズデータの保存・読み込みやガジェットを複数箇所で修正し、既存DB内の悪性オブジェクトも除去する。
- IOCの列挙

- 推奨事項
    - GiveWPをバージョン4.16.7.2へできるだけ早く更新する。
- その他
    - CVE-2026-82222は技術的に未認証RCEまで実証されているが、記事公開時点で実際の攻撃で悪用されているとの記載はない。
    - 一次ソース: https://patchstack.com/articles/unauthenticated-php-object-injection-to-remote-code-execution-on-givewp/

#### 8,300台超のGiteaサーバーがコード実行攻撃に対して脆弱

- 要約
    - Shadowserverによると、インターネット公開されたGiteaのうち8,393台が、現在悪用中の重大なコードインジェクション脆弱性CVE-2026-60004に未修正のまま残っている。

    - 実際の攻撃では、未修正Giteaサーバーへ暗号資産マイニングマルウェアを展開する事例が報告されている。

#### Claude Code Opus 5のAuto Modeを突破する
https://embracethered.com/blog/posts/2026/breaking-claude-code-opus-5-and-automode/

- 要約
    - 研究者はClaude Code Opus 5のAuto Modeに対し、単純なWebサイト要約依頼から間接プロンプトインジェクションを誘発し、60～80%の成功率でコード実行へ至る攻撃チェーンを実証した。
    - 攻撃はWebFetchからcurl利用へ誘導し、ZIP内のデコーダー実行を拒否させた上でClaude自身にPythonデコーダーを書かせ、同梱の悪性struct.pyによるモジュールシャドーイングを発火させる。
    - 悪性struct.pyは難読化コードから別Pythonプロセスを起動し、リモートステージャーとネイティブペイロードを取得・実行して、検証環境のC2へ接続するところまで到達した。
    - 別亜種では悪性コードがheadlessのClaude Codeを子プロセスとして起動し、whoami・uname・idなどの偵察やワークスペース外へのファイル書き込みも実行できた。
    - AnthropicはAuto Modeをセキュリティ境界ではなくbest-effort分類器と位置付けており、記事はサンドボックス、通信制限、監視を実質的な防御境界として強く推奨している。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - 無人のコーディングエージェントはコンテナ、VM、OSサンドボックス内で実行し、ネットワークの外向き通信を制限する。
    - エージェントの挙動を監視し、ホームディレクトリ、SSH鍵、クラウド認証情報などをエージェント実行環境へ公開しない。
    - プロセス生成や機密パスへの明示的なask/denyルールを設定し、Auto Modeの承認をコードが安全である証拠として扱わない。
- その他
    - 実環境の攻撃キャンペーンではなく研究者による実証で、Claude Code Opus 5 Auto ModeからC2接続を伴うコード実行まで成功している。
- ChatGPTの推奨事項
    - 未信頼コンテンツを処理するClaude Code等のAIエージェントは、直ちに専用VMまたはコンテナへ隔離し、外向き通信と資格情報へのアクセスを制限してください。
