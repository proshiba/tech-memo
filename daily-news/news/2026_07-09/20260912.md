#### ハッカーがClaudeを悪用し、180万件のAndroidアプリからシークレットを抽出
https://www.bleepingcomputer.com/news/security/hackers-abused-claude-to-extract-secrets-from-18m-android-apps/

- 要約
    - Anthropicは2025年12月から2026年8月にかけ、ShinyHunters関連を含む複数の攻撃者がClaudeをサイバー攻撃や諜報活動などに悪用した事例を確認・阻止した。
    - ShinyHunters関連の「frkoo」は10台のAWS EC2ワーカーで180万件のAndroid APKを取得・逆コンパイルし、TruffleHogでハードコードされたシークレットを探索した。
    - 同攻撃者はGitHub組織のメールアドレスを収集してPersonal Access Tokenを取得し、これら2つのパイプラインから得た認証情報を多数の侵害に利用した。
    - Midnight BlizzardはClaudeをマルウェア開発、フィッシング、永続化、C2、情報窃取などに利用し、20以上の政府・防衛・外交・情報機関関連組織を標的とした。
    - 中国語話者のGTG-10007もClaudeを脆弱性研究や攻撃オーケストレーションに利用し、約50組織を標的として複数の組織への侵害に成功した。

#### パスキーをテーマにしたフィッシング攻撃、Microsoft 365からのデータ窃取につながる
https://www.bleepingcomputer.com/news/security/passkey-themed-phishing-attacks-lead-to-microsoft-365-data-theft/

- 要約
    - Microsoftは、ShinyHuntersやHelixなどに関連する攻撃者が、パスキーやSSO更新を装うソーシャルエンジニアリングで企業のMicrosoftアカウントを侵害していると報告した。
    - 攻撃者は企業ITヘルプデスクを装って電話やSMSで接触し、AiTMフィッシングサイトやデバイスコード認証へ誘導して認証情報やセッショントークンを取得する。
    - 侵害後は攻撃者管理の電話番号やAuthenticatorなどのMFA方式を追加して永続化し、Microsoft Graphを使ってユーザー、権限、アプリ、ファイルなどを列挙する。
    - その後、SharePoint、OneDrive、Exchangeなどからデータを自動収集し、1時間あたり1,000件未満に抑えながら数時間から数日かけて窃取して検知を回避する。
    - Microsoftは2026年5月以降この活動を確認しており、Storm-3121、Storm-3032など同じ恐喝エコシステムに属する複数の攻撃者が関与しているとしている。
- IOCの列挙
    - passkeyhelpdesk[.]com,FQDN名,知られていない,パスキー関連の認証ページを装うフィッシングドメインとしてMicrosoftが確認,NA(IP以外)
    - secure-passkey[.]com,FQDN名,知られていない,標的企業名をサブドメインに組み込み正規のパスキー設定ページを装うフィッシングドメイン,NA(IP以外)
    - setupmypasskey[.]com,FQDN名,知られていない,パスキー設定を装って被害者を認証フローへ誘導するフィッシングドメイン,NA(IP以外)
    - add-passkey[.]com,FQDN名,知られていない,パスキー登録・追加を装うフィッシングインフラとして確認されたドメイン,NA(IP以外)
    - integratedsso[.]com,FQDN名,知られていない,SSO設定を装うフィッシングインフラとして利用されたドメイン,NA(IP以外)
    - oktasession[.]com,FQDN名,知られていない,IDプロバイダーやセッション設定を装うフィッシングインフラとして確認されたドメイン,NA(IP以外)
    - keysyncos[.]com,FQDN名,知られていない,キー同期を装って認証情報を取得するために使用されたフィッシングドメイン,NA(IP以外)
    - oskeysync[.]com,FQDN名,知られていない,キー同期を装って被害者を不正な認証フローへ誘導するフィッシングドメイン,NA(IP以外)
- 推奨事項
    - 異常なサインイン後の新規MFA登録、Microsoft Graphによる偵察、SharePoint・OneDrive・Exchangeへの不審なアクセスを監視する。
    - アカウント侵害時は既存セッションとトークンを失効し、認証情報をリセットして攻撃者が追加した認証方式やメールボックスルールを削除する。
    - フィッシング耐性のあるMFAを使用し、機密クラウドリソースを管理対象端末に限定するとともに、不要なデバイスコード認証を無効化する。
- その他
    - Storm-3121はShinyHuntersやFalcon恐喝活動、Storm-3032はBlackFileから分裂してHelixとして活動する攻撃者と関連し、主な目的は企業データの窃取と恐喝である。
    - 一次ソース: https://www.microsoft.com/en-us/security/blog/2026/09/09/passkey-themed-social-engineering-leads-identity-cloud-compromise/
- ChatGPTの推奨事項
    - Microsoft 365管理者は直ちに上記8ドメインへのアクセス履歴と異常サインイン後のMFA追加を調査し、該当アカウントの全セッションとトークンを失効する。

#### Artifactoryの脆弱性が攻撃で連鎖悪用され、バックドア型マルウェアを展開
https://www.bleepingcomputer.com/news/security/artifactory-flaws-chained-in-attacks-deploying-backdoor-malware/

- 要約
    - 複数の攻撃者がJFrog ArtifactoryのCVE-2026-42018とCVE-2026-42016を連鎖悪用し、認証を回避して管理者権限を取得している。
    - 攻撃者は内部anonymousユーザーのJWTを取得後、その低権限トークンを管理者権限へ昇格させ、5分未満で管理者アカウントを作成した事例もある。
    - 侵害後は悪意あるGroovyプラグインによるコマンド実行、長期間有効なアクセストークン作成、C2機能を備えたRust製バックドアの展開を行う。
    - さらに追加ペイロードやWebシェルを配置し、Artifactory設定、クラスタ参加キー、リポジトリ、トークン、ユーザー情報を窃取・列挙している。
    - 管理者トークンを発行できる認証バイパスの脆弱性CVE-2026-82329も実際に悪用されており、Wizはインターネットから到達可能なArtifactoryの49～62%が少なくとも1件の脆弱性を抱えると警告している。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - Artifactoryを7.111.21、7.117.28、7.125.20、7.133.29、7.146.38、7.161.20またはそれ以降へ直ちにアップグレードする。
    - インターネット公開されたインスタンスについて、不審なトークン作成、未知の管理者アカウント、プラグイン活動、列挙リクエストを調査する。
    - Artifactoryへのネットワークアクセスを信頼できるシステムのみに制限する。
- その他
    - CVE-2026-42018、CVE-2026-42016、CVE-2026-82329はいずれも実際の攻撃で悪用済みで、認証回避、権限昇格、バックドア展開などが確認されている。
    - 複数の攻撃者による活動が確認されているが、具体的な攻撃者グループ、国籍、動機について記事内では不明。
    - 一次ソース: https://www.wiz.io/blog/artifactory-under-attack-in-the-wild-exploitation-of-cve-2026-42016-cve-2026-4201
- ChatGPTの推奨事項
    - インターネット公開中のArtifactoryを直ちに修正版へ更新し、同時に不審な管理者アカウント、トークン、Groovyプラグイン、Webシェルの有無を確認する。

#### GitLab、最高深刻度のパストラバーサル脆弱性への緊急パッチ適用を呼びかけ
https://www.bleepingcomputer.com/news/security/gitlab-urges-users-to-patch-max-severity-path-traversal-flaw/

- 要約
    - GitLabは、CVSS 10.0のパストラバーサル脆弱性CVE-2026-85706について、影響を受けるセルフホスト環境を直ちに更新するよう利用者に警告した。
    - CVE-2026-85706はリポジトリコミットAPIのパス制限と認証処理の不備に起因し、未認証の攻撃者がサーバー上の任意ファイルを読み取れる可能性がある。
    - 認証情報、シークレットなどの機密情報が漏えいする恐れがあり、watchTowrはインターネット公開GitLabを対象とする実環境でのスキャン活動を既に観測している。
    - GitLabはさらに、Duo Chatへアクセスできる認証済みユーザーが機密認証情報などを取得できるCVSS 9.9のCVE-2026-87719も同時に修正した。
    - 両脆弱性はGitLab CE/EE 19.3.2、19.2.6、19.1.8で修正され、GitLab.comは既に更新済みでGitLab Dedicated利用者は対応不要とされている。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - 影響を受けるセルフマネージドGitLabを19.3.2、19.2.6、19.1.8のいずれかの修正版へ直ちにアップグレードする。
    - HTTP POSTで「/api/v4/projects/{id}/repository/commits/」へのアクセスに「file.path」パラメータを含むログを調査し、悪用試行の有無を確認する。
- その他
    - CVE-2026-85706についてGitLabは実悪用を確認していないが、watchTowrはインターネット公開GitLabに対する実環境でのプローブを既に観測しており、無差別な悪用が迫っている可能性を指摘している。
    - 特定の攻撃者、国籍、組織、動機に関する属性情報は記事内では不明。
    - 一次ソース: https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-3-2-released/
- ChatGPTの推奨事項
    - セルフマネージドGitLabを直ちに修正版へ更新し、repository commits APIへの「file.path」を含む不審なPOSTリクエストがないかログを確認する。

#### Trezor：Brevo侵害後のフィッシング攻撃で34万7,000人のユーザーが標的に
https://www.bleepingcomputer.com/news/security/trezor-347-000-users-targeted-in-phishing-attacks-after-brevo-breach/

- 要約
    - Trezorがニュースレター配信に利用する第三者メールサービスBrevoが侵害され、約34万7,000件のTrezor顧客メールアドレスを対象にフィッシングメールが送信された。
    - 攻撃メールはTrezorの正規アカウントから送信され、「Critical Security Alert: STM32 Entropy Vulnerability」という件名でウォレットの脆弱性を偽装した。
    - メール内の悪意あるリンクはアプリのダウンロードへ誘導し、利用者にウォレットバックアップ（シードフレーズ）を入力させて暗号資産を窃取しようとしていた。
    - Trezorは攻撃用ドメインを20分以内にDNSレベルで停止したが、それまでに約2,500人が悪意あるリンクをクリックしていた。
    - Trezor本体のシステムやウォレットは侵害されておらず、Brevoアカウントを停止した一方、流出した可能性のあるメールアドレスが今後の攻撃に再利用される恐れがある。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - Trezorを名乗る不審なメールのリンクをクリックしたり、個人情報やウォレットバックアップを入力したりしない。
    - 不審なメールを受信した場合は速やかに削除する。
    - ウォレットバックアップを入力してしまった場合は、直ちに資産を新しいウォレットへ移動する。
- その他
    - 脆弱性の記事ではなく、第三者メールサービスBrevoへの実際の侵害を起点としたフィッシング攻撃であり、約34万7,000人が標的となり約2,500人がリンクをクリックした。
    - 攻撃者の国籍・組織名などの属性情報は不明で、ウォレットバックアップを取得して暗号資産を窃取することを目的とした攻撃である。
    - 一次ソース: https://trezor.io/blog/news/security-incident-at-brevo-our-third-party-email-provider
- ChatGPTの推奨事項
    - フィッシング先でウォレットバックアップを入力した場合は、直ちに全資産を新しいシードで作成したウォレットへ移動する。

#### 新たなAndroidマルウェア、ファイルを暗号化し、データを窃取して被害者を嫌がらせ
https://www.bleepingcomputer.com/news/security/new-android-malware-encrypts-files-steals-data-and-harasses-victims/

- 要約
    - 新たなAndroidマルウェア「Mantax Otax」はランサムウェアとスパイウェア機能を統合し、ファイル暗号化、機密情報窃取、被害者への嫌がらせを行う。
    - インドネシアの攻撃者がGoogle Play外でホストした悪意あるAPKをフィッシングやソーシャルエンジニアリングで配布し、Accessibility権限を要求する。
    - Android 9以前ではC2から被害者固有のAES鍵を取得して共有ストレージ内のファイルを暗号化し、元ファイルを削除して「.enc」拡張子を付与する。
    - PIN、SMS・OTP、通話履歴、連絡先、閲覧履歴、Googleアカウント情報、WhatsAppやTelegramのメッセージなどを窃取し、画面やカメラも監視できる。
    - バージョン2ではダイアログ連打、全画面動画、ジャンプスケア画像、遠隔TTSなどの嫌がらせ機能を追加し、身代金支払いへの心理的圧力として利用する。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - Google Play以外から提供されるAPKをインストールしない。
    - 不審なアプリにAccessibility権限を付与しない。
    - 信頼できるアプリ提供元のみを利用する。
- その他
    - 攻撃者はインドネシアのオペレーターとされ、主にインドネシアの利用者を標的とし、情報窃取と身代金要求・恐喝を目的としている。
