#### IQVIA、健康データの匿名化が不十分として約780万ドルの制裁金
https://www.bleepingcomputer.com/news/security/iqvia-fined-78-million-for-failing-to-properly-anonymize-health-data/

- 要約
    - イタリアの個人情報保護当局は、IQVIAの健康データ処理に問題があったとして700万ユーロ（約780万ドル）の制裁金を科した。対象は一般医約800人から集めた約100万人分の患者情報。
    - IQVIAは氏名の代わりに患者ごとのコードを使っていたが、当局は、生年、診断、処方、位置情報などと組み合わせれば個人を再識別でき、匿名データとはいえないと判断した。
    - 当局は、適切な法的根拠や患者への説明を欠いた処理に加え、保存期間が定められず、2001年までさかのぼる記録が残っていた点も問題視した。一部の約3,300人分には氏名や住所なども含まれていた。
    - 当局はIQVIAに120日以内の是正を命じた。IQVIAは当局への協力と是正措置の着手を表明する一方、決定への不服申立ての権利を留保している。

    - IOC情報なし
- 推奨事項
    - IQVIAは、当局の命令に従い、継続する健康データ処理を120日以内に適法な状態へ是正する。
- その他
    - 一次ソース: https://www.gpdp.it/home/docweb/-/docweb-display/docweb/10302141
- ChatGPTの推奨事項

#### デンマークの人口登録簿で約880万人分の個人情報に不正アクセス
https://www.bleepingcomputer.com/news/security/denmark-population-registry-data-breach-affects-88-million-people/

- 要約
    - デンマークの中央人口登録簿（CPR）は、登録者約880万人分の氏名、住所、CPR番号などに不正アクセスがあったと発表した。対象には国内居住者だけでなく、国外転出者や死亡者も含まれる。
    - 攻撃者は民間企業に認められたCPR検索権限を悪用した。個人情報保護当局によると、有効なCPR番号を特定するための大量の自動照会が行われたが、企業側で権限がどう悪用されたかは調査中である。
    - 不審な照会は2026年9月に発生し、CPRの管理者は10月2日に把握した。約880万人は登録者約1,100万人の約8割に当たり、当局は当該企業のアクセスを停止して警察に届け出た。
    - 当局によると、氏名・住所の非公開登録を選んだ人の氏名と住所は、今回の不正アクセスの対象に含まれない。攻撃者の特定や事件の全容については、引き続き調査が進められている。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - 氏名、住所、CPR番号を知っている相手からの連絡でも、電話やメールでパスワードなどの機密情報を伝えない。
    - 心当たりのない連絡に警戒し、必要に応じてデンマーク当局の案内や相談窓口を確認する。
- その他
    - 攻撃者の身元は現時点では不明。

#### Dell System Updateの脆弱性、悪用されるとroot権限でコード実行の恐れ
https://www.bleepingcomputer.com/news/security/new-dell-system-update-flaw-lets-hackers-gain-root-privileges/

- 要約
    - Dellは、PowerEdgeサーバーなどの更新に使うDell System Update（DSU）の重大な脆弱性CVE-2026-86360を修正した。対象はバージョン2.3.0.0より前で、パストラバーサルに起因する。
    - Dellによると、リモートからアクセスできる未認証の攻撃者が悪用すると、ファイルシステムへのアクセスやroot権限での任意コード実行につながる恐れがある。CVSS v3.1の基本値は9.6。
    - 同じ更新では、権限昇格につながるCVE-2026-86361とCVE-2026-86362、コード実行につながるCVE-2026-63697とCVE-2026-71168も修正された。
    - DellはDSU 2.3.0.0以降への早期更新を推奨している。記事時点で、今回のDSUの脆弱性が実際の攻撃で悪用されたとの発表はない。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - Dell System Update（DSU）を2.3.0.0以降に速やかに更新する。
- その他
    - CVE-2026-86360を含む今回のDSUの脆弱性について、実際の攻撃での悪用は確認されていない。
    - 一次ソース: https://www.dell.com/support/kbdoc/en-us/000515843/dsa-2026-324-security-update-for-dell-system-update-dsu-vulnerabilities
- ChatGPTの推奨事項
    - 管理対象のPowerEdgeサーバーなどでDSUの導入状況とバージョンを確認し、2.3.0.0未満の環境を更新する。

#### Google、AIによる大量報告を受けオープンソースの脆弱性報奨制度を一部停止
https://www.bleepingcomputer.com/news/google/google-halts-open-source-bug-bounty-program-amid-ai-spam-surge/

- 要約
    - Googleは、Open Source Software Vulnerability Rewards Program（OSS VRP）における製品の脆弱性報告の受付を一時停止した。自動化された報告が急増し、その大多数が無効だったためと説明している。
    - 停止の対象はOSS VRPの製品脆弱性の新規報告であり、サプライチェーンに関する報告や未処理の既存報告は対象外。2026年10月1日より前に提出された報告にも影響しない。
    - 研究者は引き続き、オープンソースへの修正パッチをGoogle Patch Rewards Programに提出できる。Google Cloud製品に影響する対象リポジトリの脆弱性はCloud VRPで報告できる。
    - Googleは受付方法を見直しており、2027年第1四半期に更新情報を発表する予定。AIによる低品質な報告の増加は、過去にはcurlの報奨制度でも起きている。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - Googleの対象オープンソースに修正パッチを提供する場合は、Patch Rewards Programを利用する。
    - Google Cloud製品に影響する対象リポジトリの脆弱性は、Cloud VRPへ報告する。
- その他
    - これは報奨制度の受付変更に関する記事で、特定の侵害事件や悪用中の脆弱性を報じたものではない。
    - 一次ソース: https://bughunters.google.com/about/rules/open-source/google-open-source-software-vulnerability-reward-program-rules
- ChatGPTの推奨事項

#### Citrix、攻撃で悪用されたNetScalerのSAMLゼロデイ脆弱性を修正
https://www.bleepingcomputer.com/news/security/citrix-patches-netscaler-saml-zero-day-exploited-in-attacks/

- 要約
    - Citrixは、NetScaler ADC/Gatewayの脆弱性CVE-2026-88779（CVSS 8.7）の修正版を公開した。未修正の装置を狙う攻撃を確認しており、サービス拒否が発生する可能性がある。
    - 影響を受けるのは、GatewayまたはAAA機能とSAML認証を組み合わせた構成。設定内の「add authentication samlAction」または「add authentication samlIdPProfile」で該当性を確認できる。
    - 修正版は14.1-73.41、13.1-64.28。FIPS版は14.1-73.41 FIPS、13.1系FIPS/NDcPP版は13.1-37.282。直前の別の脆弱性向け更新を適用済みでも、再更新が必要な場合がある。
    - 管理者は、不正なユーザー名に外部からペイロードを取得するコマンドが含まれ、認証プロセス「nsaaad」が繰り返し異常終了する事例を報告した。
    - Citrixが確認した影響はサービス拒否であるが、セキュリティ研究者（Kevin Beaumont氏ら）の調査により、シェルコマンドを含む認証リクエストの送信や、ハニーポット上での悪意のあるマルウェアの実行が確認されており、RCEに至る可能性が指摘されている。

    - SAMLを利用するNetScalerの構成とバージョンを確認し、該当する修正版へ速やかに更新する。
    - 更新までの緩和策として、適用条件を満たす環境ではCitrix提供のGlobal Deny Listシグネチャーを利用する。
    - 攻撃の兆候があれば、認証プロセスの異常終了や関連ログを調査する。

#### 偽CAPTCHAを使うClickFix攻撃、ブラウザーキャッシュに隠したマルウェアを実行
https://cybersecuritynews.com/clickfix-fake-captcha-attack/

- 要約
    - Microsoft Threat Intelligenceは、侵害された複数のWebサイトから偽CAPTCHAを表示するClickFix攻撃を確認した。訪問者にWindowsの「ファイル名を指定して実行」を開かせ、貼り付けたコマンドを実行させる。
    - 攻撃者はVBScriptをPNG画像に見せかけ、被害者がコマンドを実行する前にブラウザーキャッシュへ保存する。コマンドはキャッシュ内の該当ファイルを探して一時ファイルにコピーし、Windows Script Hostで起動する。
    - 起動したVBScriptは端末情報を収集し、PowerShellスクリプトなど後続のペイロードを取得する。さらに正規のWindowsプロセスへコードを注入し、ブラウザーや端末に保存された認証情報を狙う。
    - 攻撃はPowerShellの実行設定変更や、Pythonのペイロードを起動するスケジュールタスクの作成も試みる。Microsoftは被害者数を公表しておらず、攻撃者も特定していない。

    - ciliabula[.]cc,FQDN名,知られていない,コードを注入されたプロセスからの通信先,NA
- 推奨事項
    - クラウド配信保護、Web保護、ネットワーク保護、アプリケーション制御、PowerShellのスクリプトブロックログを有効にする。
    - ブラウザーキャッシュの不審な操作、RunMRU、WScriptやPowerShellの子プロセス、新しいスケジュールタスクを調査する。
