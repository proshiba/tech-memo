#### SiteGuard WAFの脆弱性が悪用、root・SYSTEM権限でコマンド実行の恐れ
https://www.bleepingcomputer.com/news/security/hackers-exploit-siteguard-waf-flaw-to-run-commands-as-system-root/

- 要約
    - SiteGuard Server Editionの統計機能に、OSコマンドインジェクションの脆弱性CVE-2026-106931が存在し、実攻撃での悪用が確認された。対象サーバーでrootまたはSYSTEM権限のコマンド実行につながる。
    - 影響するのはVer2.20以降で統計機能が有効な環境。同機能は初期状態で有効であり、FreeBSD以外のApache・Nginx・IIS版は8.00 Update5未満、FreeBSD版は7.00 Update6未満が対象となる。
    - IIS版の3.10～4.00 Update4は影響を受けない。更新が困難な環境には統計処理ファイルを置き換えるパッチが提供され、サポート終了版にも適用できる。
    - 更新やパッチ適用により攻撃痕跡が消える可能性があるため、ベンダーは事前の「診断情報」取得・保管を求めている。直接サポート契約のある顧客には9月29日に通知済み。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - 修正前にウェブ管理画面の「診断情報」から「診断情報をダウンロード」を実行し、取得した情報を保管する。
    - FreeBSD以外は8.00 Update5以降、FreeBSD版は7.00 Update6以降へ更新する。
    - 更新できない場合は、ベンダー提供の統計処理ファイル差し替えパッチを適用する。
- その他
    - 悪用は確認済みだが、攻撃者・被害組織・攻撃規模・具体的手法は不明。
    - CVSS評価(CVSS:3.0/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H Base Score 7.8)はローカルアクセス・低権限を前提とする。
    - 一次ソース:
        - https://www.eg-secure.co.jp/siteguard/news/alert-202610-1
        - https://jvn.jp/en/jp/JVN88474777/index.html
- ChatGPTの推奨事項
    - SiteGuard Server Editionのバージョンと統計機能の設定を直ちに確認し、該当環境は診断情報を保全してから修正する。

#### ConnectWise経由のサプライチェーン攻撃でMicrosoft 365テナントが侵害
https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack/

- 要約
    - ConnectWise Cloud Backup（旧SkyKick）のアプリ認証情報が悪用され、顧客のMicrosoft 365テナントへの不正アクセスが確認された。ConnectWiseはサービスへのアクセスを停止し、調査と復旧対応を進めている。
    - 攻撃者はサービスプリンシパルとして認証し、顧客が事前に許可した権限でトークンを取得した。利用者のログインを伴わないためユーザー向けMFAは機能せず、メールやファイルなどへのアクセスが可能になる。
    - Huntressは記事掲載時点で162テナントの不正サインインを確認した。少なくとも1テナントでは、Cloud ManagementアプリがGlobal Administratorを取得し、別の管理・セキュリティアプリに認証情報を追加した。
    - ベンダー側の停止だけでは、顧客テナントに追加された認証情報は削除されない。アプリを無効化しても既存トークンは失効まで有効であり、ユーザーセッションの取り消しでもアプリ認証によるアクセスは終了しない。
    - 保存済みバックアップの侵害を示す証拠は報告されていないが、窃取されたデータの範囲やベンダー認証情報の取得経路は不明。調査対象によって、サインインのみ確認した事例と永続化を確認した事例がある。
- IOCの列挙
    - 144[.]172[.]64[.]128, IPアドレス, 知られていない, 不正なアプリ認証と関連するサインイン試行の送信元, グローバル
- 推奨事項
    - 関係するConnectWise・SkyKickアプリを無効化し、サービスプリンシパルのサインインと関連するGraph API操作を確認する。
    - 10月13日以降、すべてのアプリに追加されたシークレット・証明書、権限変更、OAuth同意を調査し、不正な追加を削除する。
    - Cloud BackupのアプリID「506e08f9-6e9a-4da4-942b-a099a03644ae」を起点に、Cloud Managementの各連携も確認する。
- その他
    - Microsoftは進行中のサプライチェーン攻撃と評価。攻撃者の帰属と被害全容は不明。
    - 一次ソース:
        - https://www.huntress.com/blog/vendor-credential-enables-unauthorized-access
        - https://www.connectwise.com/company/trust/advisories
- ChatGPTの推奨事項
    - 関係アプリの無効化と並行し、テナント内の全アプリの認証情報を点検して、別アプリに残された永続化を除去する。

#### Drupalが重大なRCE脆弱性2件を修正、短期間での攻撃コード出現を警告
https://www.bleepingcomputer.com/news/security/drupal-patches-critical-rce-flaws-warns-exploits-may-emerge-soon/

- 要約
    - Drupalは、コアのField UIモジュールに存在するCVE-2026-108097と、追加モジュールEntity ListのCVE-2026-108099を修正した。いずれも遠隔から任意コードを実行される可能性がある重大な脆弱性。
    - Field UIの問題はコア単独では直接悪用できないが、追加モジュールや独自コードとの組み合わせで攻撃経路が生じる。Entity Listにも同様の条件があり、両方で少なくとも1つの認証不要の攻撃経路が知られている。
    - 修正版はDrupal 10.6.19、11.3.19、11.4.10とEntity List 3.0.10。サポート終了版は更新が必要で、Drupal 12のプレリリースもbeta2未満が影響を受ける。
    - Drupalは、公表後数時間から数日で攻撃コードが開発される可能性を警告した。Field UIのアンインストールはコア側の暫定対策となるが、Drupal Stewardの保護だけではすべての攻撃経路を防げない。
- IOCの列挙
    - IOC情報なし
- 推奨事項
    - 利用ブランチに応じてDrupalコアを10.6.19、11.3.19、11.4.10以降へ更新する。
    - Entity Listを利用している場合は3.0.10以降へ更新する。
    - コアを直ちに更新できない場合は、Field UI（field_ui）をアンインストールする。
- その他
    - 記事に実環境での悪用確認の記載はなく、攻撃コードが短期間で出現する可能性への警告。
    - 一次ソース:
        - https://www.drupal.org/sa-core-2026-014
        - https://www.drupal.org/sa-contrib-2026-218
- ChatGPTの推奨事項
    - DrupalコアとEntity Listの導入状況を直ちに確認し、該当する両方の修正を適用する。
